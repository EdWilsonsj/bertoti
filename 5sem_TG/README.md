## 1º semestre — Calculadora Científica | 2024-2

**Equipe** · Suricatos · **Contexto** · Projeto acadêmico interno · **Minha função** · Desenvolvedor.

**Problema** · Disponibilizar diferentes operações matemáticas em uma aplicação de console, com navegação simples e possibilidade de realizar vários cálculos durante a mesma execução.

**Solução** · Calculadora científica com menu de seleção, operações de soma, subtração, multiplicação e divisão, cálculo de fatorial, equações do segundo grau, juros simples e compostos e conversões entre bases numéricas. A aplicação também permite concatenar strings e retornar ao menu após cada operação. O desenvolvimento ocorreu em sprints, com definição de requisitos e documentação das funcionalidades.

**Tecnologias** · Portugol e VisuAlg para os algoritmos iniciais, TypeScript para outra implementação da calculadora e Git e GitHub para versionamento do código.

**Atuação** · Participei do desenvolvimento e da integração das rotinas da calculadora, reunindo as operações em um programa com menu. Trabalhei na organização das entradas e saídas e no fluxo de execução das funcionalidades.

**Aprendizados** · Desenvolvi minha lógica de programação ao aplicar variáveis, operadores, estruturas condicionais e laços de repetição. Aprendi a dividir um problema em rotinas menores e integrar essas partes em uma aplicação utilizável.

**Soft skills** · Raciocínio lógico, colaboração e organização.

## 2º semestre — Gerenciador de Horários de Aula | 2025-1

**Equipe** · BugBusters · **Contexto** · Gestão de horários acadêmicos da FATEC · **Minha função** · Scrum Master.

**Problema** · A montagem das grades exigia conciliar cursos, semestres, disciplinas e disponibilidade dos professores. A consulta a informações dispersas tornava os ajustes demorados e dificultava perceber possíveis conflitos de horário.

**Solução** · Aplicação desktop que reúne os cadastros de cursos, disciplinas e professores, o registro de indisponibilidades e a organização da grade semestral. A interface permite distribuir e mover disciplinas na grade, respeitando os horários cadastrados, e apresenta aviso quando o professor está indisponível para a alocação.

**Tecnologias** · Java, JavaFX e FXML na aplicação desktop, SQLite com JDBC para armazenamento dos dados, Maven para dependências e build e Git e GitHub para versionamento. Excel no acompanhamento do burndown.

**Atuação** · Como Scrum Master, acompanhei as atividades e o andamento das sprints, utilizando o burndown para comparar as entregas com o planejamento. Participei das conversas de acompanhamento para identificar pendências e dificuldades que afetavam o progresso do projeto.

**Aprendizados** · Aprofundei minha compreensão de Scrum e do acompanhamento de prazos e tarefas. O projeto também ampliou meu entendimento sobre aplicações JavaFX e sobre os relacionamentos entre professores, disciplinas e cursos em um banco de dados relacional.

**Soft skills** · Comunicação, organização e gestão do tempo.

**Repositório** · [Gerenciador de Horários de Aula](https://github.com/BugBusters-Suricatos/2nd-Semester)

## 3º semestre — Plataforma de Mapeamento de Competências | 2025-2

**Equipe** · LegacyTech · **Empresa parceira** · Altave · **Minha função** · Desenvolvedor.

**Problema** · A empresa precisava conhecer melhor as competências de seus colaboradores para localizar profissionais com determinadas habilidades, formar equipes e apoiar a mobilidade interna.

**Solução** · Plataforma de perfis profissionais com competências técnicas e comportamentais, certificações e experiências. Colaboradores podem destacar suas principais habilidades, enquanto gestores consultam perfis, pesquisam competências e registram avaliações e tags. A solução inclui organização de equipes e permissões conforme o perfil de acesso.

**Tecnologias** · React, TypeScript, Vite e Tailwind CSS no front-end. Java, Spring Boot e Spring Data JPA no back-end, com MySQL para persistência, H2 para desenvolvimento local e Flyway para migrações. Git e GitHub para versionamento.

**Atuação** · Participei do desenvolvimento das funcionalidades de perfil, incluindo o cadastro das três principais habilidades do colaborador, realizado em programação em dupla. Também contribuí com a preparação e a documentação do ambiente do front-end, registrando as instruções de instalação, execução e resolução de problemas de configuração.

**Aprendizados** · Ampliei meus conhecimentos em React e TypeScript e na organização de uma aplicação web integrada a uma API. Com o cadastro de habilidades, compreendi melhor a representação e a padronização de competências. A documentação técnica desenvolveu minha capacidade de tornar a configuração do projeto reproduzível.

**Soft skills** · Comunicação, resolução de problemas e aprendizado contínuo.

**Repositórios** · [Front-end](https://github.com/LegacyTec/altave-front) · [Back-end](https://github.com/pedromattos11/backend-altave)

## 4º semestre — Sistema de Gestão de Manutenções | 2026-1

**Equipe** · LegacyTech · **Empresa parceira** · Altave · **Minha função** · Desenvolvedor.

**Problema** · Equipamentos instalados em diferentes localidades exigiam um controle centralizado de manutenções, contratos, técnicos e prazos. A gestão manual dificultava acompanhar os serviços e consultar o histórico de cada ativo.

**Solução** · Sistema web para gerenciar contratos, plantas, equipamentos, colaboradores e ordens de manutenção. O fluxo atende administradores, supervisores, planejadores e técnicos, desde a abertura da ordem e a atribuição do responsável até o registro da execução em checklist. Painéis apresentam indicadores e ordens em atraso para apoiar o acompanhamento operacional.

**Tecnologias** · Vue.js, TypeScript, Vite, Tailwind CSS, Axios e Leaflet no front-end. Java, Spring Boot e Spring Data JPA no back-end, PostgreSQL para persistência e Swagger/OpenAPI para documentação da API. Git e GitHub para versionamento.

**Atuação** · Atuei no desenvolvimento da interface administrativa, incluindo a criação do protótipo inicial em Vue. Participei da organização das telas e dos fluxos de consulta de contratos, plantas e ativos, relacionando as informações exibidas às necessidades do administrador.

**Aprendizados** · Aprofundei meus conhecimentos em Vue e na organização de interfaces a partir de regras de negócio. Compreendi melhor a relação entre os dados de contratos, equipamentos e manutenções e a importância de apresentar informações adequadas a cada perfil de usuário.

**Soft skills** · Adaptabilidade, autonomia e atenção às necessidades do usuário.

**Repositório** · [Sistema de Gestão de Manutenções — Altave](https://github.com/LegacyTec/4Sem2026-1)
